# Architecture Decision Records

ADR фіксує глобальне рішення, яке впливає на кілька задач або майбутні інсталяції. Нумеруйте файли послідовно: `0001-short-title.md`.

```markdown
# ADR 0001: Title

## Status

Proposed | Accepted | Superseded

## Context

What problem and constraints require a decision?

## Decision

What exactly was decided?

## Consequences

Positive effects, costs, risks, and migration impact.

## Alternatives considered

Options rejected and why.
```

`Accepted` встановлює власник. Агент може підготувати `Proposed`, але не приймати глобальне рішення самостійно.
